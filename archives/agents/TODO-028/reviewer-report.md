## 要修正

### 1. 行末に近づくと、入力欄が直前に入力した字を隠す

- `index.html:1801-1808`（`placeInput`）
- 何が問題か: 行末の手前では入力欄が `maxLeft` で左に寄せられる。入力欄の上端は
  「今の字の下端 + `.typed` の高さ + 3」だが、今の字の `.typed` はまだ空なので高さが 0 で、
  入力欄は入力した字の段にそのまま重なる。その結果、済んだ字の下に出した字が入力欄に隠れる
- 根拠（実測）: 行の 3 字手前まで打った状態で、入力欄と重なる `.typed > span` を数えた
  - 1280: 行 36 字、入力欄 left=837・top=306、隠れた字 **7 字**
  - 375: 行 14 字、隠れた字 **9 字**
  - 画像: `reviewer-lineend-1280.png`（緑の字の右端の数字が入力欄の下に入っている）
- 今の字の `.typed` が空のときの値: `offsetHeight` = 0、今の字の下端 303・入力欄の上端 306
  （`.typed` の下端も 303）。TODO-028 の目的（打った字をお手本の真下で見せる）が、
  毎行の最後の 7〜9 字で効かない

### 2. 入力した字の色も 0.6 の不透明度で薄くなる

- `index.html:317-320`（`.char.done { opacity: 0.6 }`）
- 何が問題か: `opacity` は子孫にも効くので、`.char.done` の中の `.typed .ok` / `.ng` も 60% で描かれる。
  TODO の「お手本は済んだ字を薄くし、緑・赤は入力した字に付ける」の意図と食い違うかもしれない
- 根拠（実測）: 済んだ字の `opacity` = 0.6、中の `.ok` の `color` = rgb(52, 211, 153)（色そのものは
  不透明だが、親の opacity で合成される）。画像 `reviewer-lineend-1280.png` でも緑が暗い。
  意図どおりかは判断しない（実害は未確認）

### 3. 余計な字が今の字の下に付くと、入力欄の高さが変わる

- `index.html:1802-1803`
- 何が問題か: 確定の最後の余計な字は今の字（次に打つ字）の下に付く。そのときだけ `.typed` に
  高さが出て、入力欄が 1 段下がる。普段は入力欄が入力した字の段にあり、余計な字があるときだけ
  その下に出るので、確定のたびに入力欄の上下の位置が揺れる
- 根拠（実測）: 余計な字 10 字を今の字の下に付けたとき `.typed` の高さ 25、入力欄の上端 331。
  付いていないときは 306。行の間隔（`line-height: 4` で約 83px）には収まっていた。実害は未確認
