# TODO-001. 長文タイピング練習ソフトのHTML1ファイルを実装する

## きっかけ

日本語の長文タイピングを練習できるソフトウェアを単一のHTMLファイルで作成したいという要望。
外部ライブラリやビルド設定が不要で、ブラウザで開くだけで即座に動作する使い勝手を追求した。

## やったこと

- **単一HTML完結設計 (`index.html`)**:
  - HTML, CSS, JavaScriptを1ファイルに統合。外部CDNやファイル依存を一切持たず、オフラインでも即時起動可能。
  - レスポンシブ＆フルビューポート対応のダッシュボードレイアウト。
  - ダークモードとライトモードのワンクリック切り替え対応。
- **実践的日本語タイピングエンジン**:
  - IME（日本語入力システム）での変換・確定に自然に対応する入力突き合わせ処理（`compositionstart` / `compositionupdate` / `compositionend` / `input`）。
  - 入力済み文字（緑色）、現在入力中フォーカス（青色ハイライト枠）、未入力文字のリアルタイム色分け表示。
  - 現在入力位置へのコンテナ内自動スクロール追従（`container.scrollTo`）。
  - 入力目安（次の文）のプレビュー表示。
- **名作長文プリセット＆カスタム文章機能**:
  - 青空文庫のパブリックドメイン名作5篇（太宰治『走れメロス』、中島敦『山月記』、夏目漱石『吾輩は猫である』、宮沢賢治『注文の多い料理店』、芥川龍之介『羅生門』）を内蔵。
  - 任意の長文テキストを貼り付けて練習できるカスタム文章設定モーダル。
- **リアルタイムメトリクス＆リザルト画面**:
  - 経過時間、タイピング速度（CPM: 文字/分）、進捗率、正確率、ミス打鍵数のリアルタイム計測。
  - 完了時の総合評価ランク（SS / S / A / B / C）算出およびモーダル表示。
- **Web Audio APIによる効果音**:
  - 外部音源ファイル不要で、軽快な打鍵音、確定音、警告音、完了ファンファーレ音をプログラマティックに合成生成（ON/OFF切り替え可能）。

## テスト

- **Chromiumヘッドレス環境での動作・レンダリング検証**:
  - ダークテーマおよびライトテーマの初期画面表示
  - 仮想入力によるタイピング進行、文字ハイライト（Done/Active/Pending）、進捗バーおよび統計の更新
  - タイピング完了時のリザルトモーダル表示とスコア集計
  - カスタム文章設定モーダルの表示
- **画面確認**:
  - 各状態のスクリーンショットを撮影し、`imv` にて目視確認を実施。
