## きっかけ

利用者に「記録はどこに保存されるの？」と聞かれた。記録は localStorage に入るので、
ブラウザや開いた URL が変わると別の記録になるが、README に書いていなかった。

## やったこと

- `README.md` の「履歴」の節に、記録はブラウザごと・開いた URL ごとに別々に残ることを 1 項目足した
- localStorage のキー名や読み出し方は書かない（利用者の指定）
