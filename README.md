# 日本語長文タイピング

ブラウザ単一のHTMLファイル（`index.html`）で動作する日本語長文タイピング練習Webアプリケーションです。
外部ライブラリやビルド工程は不要で、ファイルをブラウザで開くだけですぐに練習を開始できます。

**すぐに試す: https://ytani01.github.io/jp-long-typing/**

## 主な特徴

- **実践的な日本語入力・変換対応**:
  - IME（日本語入力システム）をONにした状態で入力・変換・確定して長文を打ち進める、実務・執筆に即した実践スタイル。
  - 文節や句読点ごとにスムーズに入力確定が可能。
- **Claudeニュース自動取得機能**:
  - 起動時と「ニュース更新」で、[Claude Platform リリースノート](https://platform.claude.com/docs/ja/release-notes/overview)の新しい 3 日分と、[Claude Code の CHANGELOG](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md) の最新版の先頭 8 項目（英語）を取得。
  - リリースノートは CORS を許していないため、公開の CORS プロキシ（allorigins）を経由する。取得できないときは内蔵のデータを使う。
  - Markdown のリンク・コード・強調の記法は外して練習文にする。
- **NHKニュース自動取得機能**:
  - オンライン起動時に最新のNHKニュースRSSフィードを自動取得。
  - 主要ニュースのまとめ長文や個別記事を即座に練習文として練習可能（オフライン・障害時の自動キャッシュフォールバック対応）。
- **時間制限モード（30秒 / 1分 / 3分 / 5分 / 無制限）**:
  - 残り時間のカウントダウン表示に対応（残り10秒未満で警告色表示）。
  - 時間切れ時の自動終了と打鍵成績（CPM、文字数、正確率、ランク）集計。
- **長文プリセット内蔵**:
  - このアプリの特徴をまとめた文章
  - Claude Code 日本語ドキュメントの抜粋: 概要、クイックスタート、一般的なワークフロー
  - 青空文庫: 太宰治『走れメロス』、夏目漱石『吾輩は猫である』、芥川龍之介『羅生門』
- **起動時の既定**: 練習文はこのアプリの特徴をまとめた文章、制限時間は 30 秒
- **練習文の整え方**: 日本語の隣の空白は詰め、英単語の間の空白は半角スペース 1 個にする。全角・半角は変えない
- **全角・半角の判定**: 英数字や記号は、形が同じなら全角でも半角でも正解（（ と (、－ と - と ー、〜 と ~、“ と " など）
- **カスタム文章練習機能**:
  - 練習したい任意の長文（ニュース記事、論文、書籍の一節など）を貼り付けて練習可能。
- **リアルタイム測定＆リザルト表示**:
  - 経過時間、タイピング速度（CPM: 1分あたりの入力文字数）、進捗率、正確率、ミス打鍵数のリアルタイム集計。
  - 練習完了時の成績評価ランク（SS / S / A / B / C）の算出。CPM と正確率の両方を満たす、いちばん上のランクになる。

    | ランク | CPM | 正確率 |
    |--------|-----|--------|
    | SS | 350 以上 | 98% 以上 |
    | S  | 280 以上 | 95% 以上 |
    | A  | 200 以上 | 90% 以上 |
    | B  | 140 以上 | 85% 以上 |
    | C  | 上のどれにも当たらないとき | |

    CPM は正しく入力した文字数 ÷ 経過秒数 × 60、正確率は正しく入力した文字数 ÷（正しく入力した文字数 ＋ ミス打鍵数）。どちらも整数に丸める。時間切れのときの経過秒数は制限時間。
- **集中できるモダンUI**:
  - ダークモード / ライトモード対応。
  - 現在の入力位置への自動スクロール追従。
  - Web Audio APIによる軽快な打鍵音・確定音・エラー音（外部音声ファイル不要、ON/OFF切替可能）。

## 起動方法

ブラウザで `index.html` を直接開くか、ローカルサーバーで起動します:

```bash
# ブラウザで直接開く場合
xdg-open index.html

# ローカルサーバーで開く場合
python3 -m http.server 8080
```
