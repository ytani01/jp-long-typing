# 日本語長文タイピング

ブラウザ単一のHTMLファイル（`index.html`）で動作する日本語長文タイピング練習Webアプリケーションです。
外部ライブラリやビルド工程は不要で、ファイルをブラウザで開くだけですぐに練習を開始できます。

**すぐに試す: https://ytani01.github.io/jp-long-typing/**

https://github.com/user-attachments/assets/6a59d1eb-0fea-4e91-b951-f491ec981455

練習文を選び、読みを打って変換・確定するたびに緑の字が進む。時間切れで結果が出て、履歴に苦手の分析が出る。
変換は Chromium の DevTools Protocol で再現したもので、実際の IME ではない。撮り直しは `node tools/record-demo.mjs`（先に `python3 -m http.server 8080`）。

## 主な特徴

- **実践的な日本語入力・変換対応**:
  - 入力・変換・確定をくり返して長文を打ち進める、実務・執筆に即した実践スタイル。
  - 文節や句読点ごとにスムーズに入力確定が可能。
- **ニュースの埋め込み**:
  - ブラウザでは何も取得しない。ニュース・リリースノート・CHANGELOG・ブログは、cron が 3 時間ごとに `update-notes.sh` で取得して `index.html` に埋め込み、commit・push する。手でも `/update-release-notes` で更新できる（使い方は [docs/update-release-notes.md](docs/update-release-notes.md)）。
  - 練習文の選択欄の各行の末尾に、配信日時を日本時間で出す（例: `・Claude Code 2.1.312（英語） (10/28 05:24)`）。Claude Platform リリースノートは名前に日付が入っているので付けない。配信日時が取れなかったものは、取得した日時になる。日時が無いデータでは出さない。
  - [Claude Code の CHANGELOG](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md) は、最新版の先頭 8 項目の英語（`FALLBACK_CLAUDE_CODE`）と、最新 3 版の日本語訳（「Claudeニュースまとめ」には含めない）を埋め込む。版の日時は GitHub のリリース日時。
  - [Claude Platform リリースノート](https://platform.claude.com/docs/en/release-notes/overview)の新しい 3 日分は、日本語に訳して埋め込む。
  - [CachyOS のブログ](https://cachyos.org/blog/)の最新 3 件は、英語の本文と日本語訳を埋め込む（選択欄の「🐧 CachyOS」）。
  - Markdown のリンク・コード・強調の記法は外して練習文にする。
- **NHKニュース**:
  - 最新 6 件を `FALLBACK_NHK_NEWS` に埋め込む（`update-notes.sh`、訳さない）。主要ニュース（最大 6 本）を 1 つのまとめにして練習できるほか、まとめの下の行から記事を 1 本ずつも練習できる。
  - 選択欄のまとめの行に最新記事の配信日時（例: `📰 NHK主要ニュースまとめ (6本・10/28 22:22)`）、記事ごとの行にその記事の配信日時（例: `・スペイン 列車どうしの衝突事故… (10/28 23:50)`）を日本時間で出す。日時が読めないときは出さない。
  - RSS の要約は 100 字前後で「…」と切れるので、最後の「。」まで残す。「。」が無い要約は外し、見出しだけにする。
- **時間制限モード（30秒 / 1分 / 3分 / 5分 / 無制限）**:
  - 残り時間のカウントダウン表示に対応（残り10秒未満で警告色表示）。
  - 制限時間の選択とリセットは、残り時間の横にある。入力欄で Esc を押してもリセットできる（変換中の Esc は変換の取り消しになる）。
  - 時間切れ時の自動終了と打鍵成績（CPM、文字数、正確率、ランク）集計。
- **長文プリセット内蔵**:
  - このアプリの特徴をまとめた文章
  - 青空文庫: 太宰治『走れメロス』、夏目漱石『吾輩は猫である』、芥川龍之介『羅生門』
- **起動時の既定**: 練習文はこのアプリの特徴をまとめた文章、制限時間は 30 秒
- **練習文の整え方**: 日本語の隣の空白は詰め、英単語の間の空白は半角スペース 1 個にする。全角・半角は変えない
- **全角・半角の判定**: 英数字や記号は、形が同じなら全角でも半角でも正解（（ と (、－ と - と ー、〜 と ~、“ と " など）
- **カスタム文章練習機能**:
  - 練習したい任意の長文（ニュース記事、論文、書籍の一節など）を貼り付けて練習可能。
- **リアルタイム測定＆リザルト表示**:
  - 経過時間、タイピング速度（CPM: 1分あたりの入力文字数）、進捗率、正確率、ミス打鍵数のリアルタイム集計。
  - 練習完了時の成績評価ランク（SS / S / A / B / C）の算出。CPM と正確率の両方を満たす、いちばん上のランクになる。

    | ランク | CPM | 正確率 |
    |--------|-----|--------|
    | SS | 350 以上 | 98% 以上 |
    | S  | 280 以上 | 95% 以上 |
    | A  | 200 以上 | 90% 以上 |
    | B  | 140 以上 | 85% 以上 |
    | C  | 上のどれにも当たらないとき | |

    CPM は正しく入力した文字数 ÷ 経過秒数 × 60、正確率は正しく入力した文字数 ÷（正しく入力した文字数 ＋ ミス打鍵数）。どちらも整数に丸める。時間切れのときの経過秒数は制限時間。
- **履歴**:
  - 結果が出るたびに（完走か時間切れ）、日時・文章名・制限時間・ランク・所要時間・CPM・文字数・正確率をブラウザ（localStorage）に保存する。新しい 20 回分には、苦手の分析のための記録（字の種類ごとの字数・時間・誤り、誤った字の上位 20 字と前後の字、詰まった語）も残す。リセットで中断したものは残さない。
  - 記録はブラウザごと、開いた URL ごとに別々に残る。別のブラウザで開いたり、`index.html` を直接開いたときとローカルサーバーで開いたときを行き来したりすると、それぞれ別の履歴になる。
  - ヘッダーの「履歴」から新しい順の一覧を開ける。件数の上限は無く、1 件ずつ削除できる。
  - 一覧の上に苦手の分析を出す。新しい 20 回分から、字の種類（ひらがな・カタカナ・漢字・英数字・記号）ごとの誤り率と 1 字あたりの時間（確定 1 回にかかった時間を字数で割ったもの）、よく誤る字、詰まった語（確定までに時間がかかった語）を集計し、アドバイスの文を添える。CPM と正確率の傾向は、分析を始める前の結果も使い、1 字も打たなかった回は外す。
  - 分かるのは確定した字のどこで誤ったか・詰まったかまで。ローマ字の打ち間違いは IME の中で起きるので拾えない。
- **集中できるモダンUI**:
  - ダークモード / ライトモード対応。
  - 現在の入力位置への自動スクロール追従。
  - Web Audio APIによる軽快な打鍵音・確定音・エラー音（外部音声ファイル不要、ON/OFF切替可能）。

## 起動方法

ブラウザで `index.html` を直接開くか、ローカルサーバーで起動します:

```bash
# ブラウザで直接開く場合
xdg-open index.html

# ローカルサーバーで開く場合
python3 -m http.server 8080
```

## cron の更新と開発（TODO-041）

cron の `update-notes.sh` は、作業中のコミットを push しないよう、始める前に `git fetch` して origin/master と比べる。
master でない・未 push のコミットがある・origin と分岐している、のどれかなら、ログに理由を残して何もせず終わる。
そうでなければ、origin/master から作った一時的な worktree の中で更新・commit・push を行い（手元の作業ツリーと master には触れない）、worktree で作った commit の SHA だけを送る。
終わったあと、手元が master で、commit していない変更が無く、早送りできるときだけ `git merge --ff-only` で取り込む（できなければログに残すだけ）。
つまり、開発は cron を流すマシンでしてよいが、**commit したら push して、cron が動ける状態に戻す**。

- Claude Code でこのリポジトリを開くと、`.claude/settings.json` の SessionStart hook（起動と `/clear` のとき）が fetch（上限 5 秒）して、遅れていれば「先に pull」、未 push があれば「cron は見送り中」と知らせる
- commit 時に origin より遅れていれば警告する pre-commit hook は `githooks/` にある（警告だけで、commit は止めない）。clone ごとに一度だけ、有効にする

  ```bash
  git config core.hooksPath githooks
  ```
